这是一份关于西方经济学发展脉络的系统梳理。为了让你更清晰地把握其演变逻辑，我将整个发展史划分为**重商/重农主义（萌芽）、古典经济学（奠基）、新古典经济学（微观确立）、宏观经济学（凯恩斯革命）以及现代主流经济学（百家争鸣）**五个主要阶段。

### 西方经济学发展脉络一览表

| 发展阶段 | 时间跨度 | 代表流派/名称 | 主要代表人物 | 核心观点与理论贡献 | 历史背景与演变逻辑 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **一、前科学阶段** | 15世纪-17世纪中期 | **重商主义**<br>(Mercantilism) | 托马斯·孟<br>柯尔贝尔 | **金银即财富**；主张贸易保护，鼓励出口限制进口（贸易顺差）。 | 资本主义原始积累时期，商业资本占据统治地位。 |
| | 17世纪中期-18世纪中期 | **重农学派**<br>(Physiocracy) | 魁奈<br>杜尔哥 | **“自然秩序”**；认为只有农业创造“纯产品”（财富）；主张自由放任。 | 反对重商主义对商业的过度干预，为古典经济学奠定基础。 |
| **二、古典经济学**<br>(体系建立) | 1776年-19世纪70年代 | **古典经济学派**<br>(Classical School) | **亚当·斯密**<br>大卫·李嘉图<br>马尔萨斯<br>J.S.穆勒 | **“看不见的手”**；劳动价值论；自由放任；比较优势理论；萨伊定律（供给创造需求）。 | 工业革命兴起，产业资本取代商业资本。**经济学成为一门独立科学的标志。** |
| **三、新古典经济学**<br>(微观大厦) | 19世纪70年代-20世纪30年代 | **边际革命**<br>(Marginal Revolution) | 杰文斯<br>门格尔<br>瓦尔拉斯 | **边际效用价值论**；引入数学分析；一般均衡理论。 | 经济学从关注“生产与增长”转向“资源配置与效率”。 |
| | 1890年-1930s | **马歇尔体系**<br>(Marshallian Economics) | **阿尔弗雷德·马歇尔**<br>庇古 | **供求论**（剪刀差）；局部均衡分析；弹性理论；消费者剩余。 | 折中综合了古典学派和边际学派，**构成了现代微观经济学的基础。** |
| **四、宏观经济学**<br>(凯恩斯革命) | 1936年-1970年代 | **凯恩斯主义**<br>(Keynesianism) | **凯恩斯**<br>汉森 | **国家干预**；有效需求不足导致危机；工资/价格刚性；财政政策优于货币政策。 | **应对1929大萧条。**打破了“市场自动出清”的幻想，**宏观经济学诞生。** |
| | 1950s-1970s | **新古典综合派**<br>(Neoclassical Synthesis) | **萨缪尔森**<br>希克斯<br>托宾 | **IS-LM模型**；微观用新古典（市场有效），宏观用凯恩斯（政府干预）；菲利普斯曲线。 | 二战后西方经济繁荣期，将微观与宏观整合成标准教科书体系。 |
| **五、新自由主义与现代发展** | 1970s-1980s | **货币主义**<br>(Monetarism) | **弗里德曼** | **“通胀通过是货币现象”**；单一规则货币政策；反对过度干预；自然失业率。 | **应对70年代“滞胀”**（停滞+通胀），凯恩斯主义失灵。 |
| | 1970s-1980s | **供给学派**<br>(Supply-side) | 拉弗<br>费尔德斯坦 | **拉弗曲线**；减税刺激供给；强调萨伊定律回归。 | 里根经济学和撒切尔夫人的政策基础。 |
| | 1970s-1990s | **新古典宏观**<br>(New Classical) | 卢卡斯<br>巴罗 | **理性预期**；市场连续出清；政策无效性命题。 | 强调微观基础，认为政府无论是财政还是货币政策都很难长期有效。 |
| **六、当代融合** | 1980s-至今 | **新凯恩斯主义**<br>(New Keynesian) | 曼昆<br>斯蒂格利茨 | 坚持凯恩斯的核心观点（非市场出清、政府干预），但引入了**微观基础**（如菜单成本、效率工资）来解释价格粘性。 | 现代主流宏观经济学的主要流派之一，与新古典宏观对立统一。 |
| | 20世纪中后期-至今 | **其他重要分支** | 科斯、诺斯<br>纳什<br>卡尼曼 | **新制度经济学**（交易成本、产权）；**博弈论**；**行为经济学**（心理学与经济学结合）。 | 经济学疆域的拓展，修正了“完全理性人”假设，关注制度与心理因素。 |

### 发展脉络的逻辑总结

为了更好地理解这个表格，你可以抓住以下三条主线（Thread）：

#### 1. 对“市场机制”看法的演变（政府 vs 市场）
*   **古典/新古典：** 笃信市场完美，主张自由放任（守夜人）。
*   **凯恩斯：** 发现市场缺陷（大萧条），主张政府干预（看得见的手）。
*   **货币/新古典宏观：** 批评政府失灵（滞胀），主张回归市场，限制政府。
*   **新凯恩斯：** 承认市场有摩擦（粘性），主张适度的、有微观基础的干预。

#### 2. 研究方法的演变
*   **文学/哲学描述**（亚当·斯密时期）
    $\downarrow$
*   **简单的几何与代数**（李嘉图时期）
    $\downarrow$
*   **边际分析与微积分**（边际革命）
    $\downarrow$
*   **一般均衡与复杂数学建模**（萨缪尔森时期）
    $\downarrow$
*   **博弈论与实验方法**（现代）

#### 3. 研究重心的演变
*   **财富的性质与增长**（斯密：国家怎么变富？）
    $\downarrow$
*   **资源的配置与效率**（马歇尔：价格怎么定？资源怎么分？）
    $\downarrow$
*   **资源的利用与就业**（凯恩斯：为什么失业？怎么把闲置资源用起来？）
    $\downarrow$
*   **长期增长与微观机制**（现代：制度、技术进步、人类行为如何影响经济？）

希望这个表格和逻辑梳理能帮你建立起西方经济学的立体框架！
