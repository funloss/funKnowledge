根据提供的来源，我为您将西方哲学史的发展脉络整理成下表：

| 时期 | 核心人物 | 主要思想 / 流派 | 历史影响与贡献 |
| :--- | :--- | :--- | :--- |
| **古希腊时期** | **泰勒斯** (Thales) | 米利都学派；**水是万物之源** | 被誉为“哲学之父”，首次尝试用理性而非神灵解释宇宙。 |
| | **赫拉克利特** (Heraclitus) | **万物流变**，对立统一；火是世界的元素 | 强调自然的流动与无常，提出“逻各斯”概念影响了后世。 |
| | **巴门尼德** (Parmenides) | 伊利亚学派；**存在是唯一且不变的** | 西方形而上学和本体论的奠基者，区分了真理之路与意见之路。 |
| | **苏格拉底** (Socrates) | 转向**道德与人事**研究；苏格拉底式对话 | 哲学史的转折点，将理性和知识视为生活的核心。 |
| | **柏拉图** (Plato) | **理念论**（形式论）；划分感性与理知世界 | 建立了系统的形而上学体系，认为理知世界才是真实的实在。 |
| | **亚里士多德** (Aristotle) | **第一哲学**；实体学说；逻辑学（三段论） | 形而上学创始人，确定了以“实体”为核心的范畴体系。 |
| **中世纪时期** | **圣·奥古斯丁** (Augustine) | 调和基督教信仰与柏拉图哲学 | 确立了经院哲学的早期框架。 |
| | **安瑟伦** (Anselm) | 关于上帝存在的**本体论论证** | 认为上帝作为“最完美的善”必然存在。 |
| | **托马斯·阿奎那** (Aquinas) | 托马斯主义；利用亚里士多德哲学服务教义 | 通过宇宙的合理性论证上帝是“第一动因”。 |
| **近代时期** (17-18世纪) | **培根**、**笛卡尔** | **认识论转向**；“我思故我在” | 笛卡尔确立了“主体”作为哲学研究的起点。 |
| | **洛克**、**休谟** | **经验主义**；否定先天观念；怀疑论 | 提出知识来源于感性材料，休谟将经验论推向极致。 |
| | **康德** (Kant) | **批判哲学**；先验唯心论；哥白尼式革命 | 整合经验论与唯理论，确立了知性为自然立法的原则。 |
| **19世纪** | **黑格尔** (Hegel) | **绝对唯心主义**；辩证法体系 | 近代哲学的集大成者，认为现实是绝对精神的展开过程。 |
| | **叔本华** (Schopenhauer) | **生命意志**；悲观主义 | 认为意志是物自体，人生在痛苦与无聊间摇摆。 |
| | **祁克果** (Kierkegaard) | **存在主义之父**；个人生存的真理 | 批判黑格尔的抽象体系，强调个人选择与信仰的飞跃。 |
| | **尼采** (Nietzsche) | **权力意志**；重估一切价值；超人 | 宣布“上帝之死”，揭示西方文明的危机并追求自我超越。 |
| **当代时期** (20世纪至今) | **弗雷格**、**罗素** | **分析哲学**；数理逻辑；意义与指称 | 开启语言学转向，主张通过逻辑分析澄清哲学问题。 |
| | **维特根斯坦** (Wittgenstein) | 逻辑图像论；**语言游戏** | 前期关注逻辑结构，后期强调语言在生活形式中的使用。 |
| | **胡塞尔** (Husserl) | **现象学**；意向性；回到事物本身 | 致力于为所有科学奠定先验的基础，研究意识结构。 |
| | **海德格尔** (Heidegger) | **基础存在论**；此在 (Dasein)；存在的意义 | 探讨“存在的真理”，批判西方形而上学对存在的遗忘。 |
| | **萨特** (Sartre) | 存在主义；**存在先于本质**；绝对自由 | 强调人的自由选择及对其后果承担的绝对责任。 |
| | **霍克海默**、**阿多诺** | **批判理论**；启蒙的辩证法 | 法兰克福学派代表，反思工具理性对人的宰制。 |
| | **福柯**、**德里达** | **后现代主义**；知识考古学；**解构** | 福柯揭示权力与知识的关系；德里达消解在场形而上学。 |

**比喻：** 如果把西方哲学史比作一座**摩天大楼**，古希腊哲学家打下了关于“地基材料”的基础；中世纪哲学家为大楼修建了通往“神殿”的阶梯；近代哲学家安装了认识世界的“窗户”；现代哲学家则在检查这些“窗户”是否扭曲了光线，甚至在怀疑整座大楼的“设计图”本身是否合乎理性。
